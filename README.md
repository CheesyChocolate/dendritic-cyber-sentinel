## Description

In today's era of technology and cyber information, almost every electronic
device is connected to a network, and that makes the security of networks a
great matter; therefore, anomaly detection plays an important role in facing
cyber threats.

This project proposes an algorithm for anomaly detection by integrating the
Dendritic Cell Algorithm (DCA) and Enhanced Genetic Algorithm (EGA) for
optimizing parameter selection. The DCA, inspired by the human immune system,
is adept and distinguishing between regular and irregular patterns in data. Its
performance is highly affected by the fine-tuning of its parameters which is
crucial for detection accuracy. To address this we employ a Genetic Algorithm
(GA) to optimize DCA, ensuring more effective detection.
